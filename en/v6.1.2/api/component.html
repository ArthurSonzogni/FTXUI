CatchEvent ​

cpp
ComponentDecorator CatchEvent(std::function< bool(Event)> on_event);

Decorate a component, using on_event to catch events. This function must returns true when the event has been handled, false otherwise.

Parameters:

  • on_event: The function drawing the interface.

Example

cpp
auto screen = ScreenInteractive::TerminalOutput();
auto renderer = Renderer([] { return text("Hello world"); });
renderer |= CatchEvent([&](Event event) {
  if (event == Event::Character('q')) {
    screen.ExitLoopClosure()();
    return true;
  }
  return false;
});
screen.Loop(renderer);

Examples: component/canvas_animated, component/custom_loop, component/input, component/print_key_press

A list of components to be stacked on top of each other. Events are propagated to the first component, then the second if not handled, etc. The components are drawn in the reverse order they are given.   • children: The list of components.

  children_1,
  children_2,
  children_3,
  children_4,
});
